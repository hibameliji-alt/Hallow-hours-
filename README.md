# The Mystery Files 3D

A third-person 3D mystery game: 1,000 cases. Style your investigator (skin, hair, coat, hat, name), then in every case you arrive outside a new house, walk through the front door, find the body and question every guest. One guest lied about where they were. One `index.html`, no build step. Three.js loads from cdnjs, so you need an internet connection.

Controls: on-screen stick or WASD/arrow keys to walk, drag the view to look around, "Question" button or E/Space when you're next to a guest.

Deploy: add `index.html` to a GitHub repo, then Settings > Pages > Deploy from a branch (`main`, `/ (root)`).
